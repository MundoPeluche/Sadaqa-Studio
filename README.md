# Sadaqa Studio

> 🚧 **WORK IN PROGRESS (WIP)**
> Sadaqa Studio is currently under active development. Its modules, features, interface, compatibility, and architecture may change throughout development.

**Sadaqa Studio** is a project that aims to bring different AI-assisted multimedia creation and editing tools together into a single platform.

## 🚧 Project Status

Sadaqa Studio is currently a **Work in Progress** and should not yet be considered a final or stable release.

This repository is being used to progressively develop, organize, and test the different components of the project. Some features may be incomplete, disabled, experimental, or not yet available.

## 🧩 Modules

Sadaqa Studio is organized into several modules, including:

* 🎬 **SadaDance** — AI video generation.
* 🎵 **SadaVox** — Changes or translates song lyrics while preserving the musical and vocal performance.
* 🖼️ **SadaVision** — AI image generation using visual references.
* ✏️ **SadaEdit** — Image and video editing.
* 🗣️ **SadaClone** — Voice and singing voice cloning.
* 🌐 **ElevenSadaqas** — Video and speech translation.
* 🧹 **SadaErase** — Object and element removal from multimedia content.

The availability and functionality of each module may change as development continues.
